# 长伴咨询网站源码

当前版本：0.3.0。React / TypeScript / Vite，沿用现有视觉与业务介绍。

## 使用

需要 Node.js 22.18 或以上、pnpm。进入本目录后运行：

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm preview
```

访问 `http://127.0.0.1:3000/`。日常修改使用 `pnpm dev`。
构建产物在 `dist/static/`，包含 `CNAME` 与 `.nojekyll`。

## 第一轮保留的变化

- 恢复可维护源码，保留锁文件及原始本地目录。
- 首页、预约、服务咨询及部分页脚入口连接到实际页面区域。
- 手机菜单选择后关闭，支持 Escape，补上按钮名称及键盘焦点样式。
- 咨询表单生成邮件草稿，访客必须自行发送；支持复制、拨号、邮件入口。
- 必填项简化为姓名、联系方式、咨询内容，公司及服务类型选填。
- 中文网页标题、简介、语言设置与固定导航避让。
- 撤下失效的办公图片占位图；修复装饰元素引起的横向溢出。

## 第二轮变化

- 图片转为随网站发布的 WebP，首屏提供两个尺寸，团队与页脚图片延后加载，保留宽高避免布局跳动。
- 本地 SVG 图标替代外部图标字体，轻量 CSS 动效替代动画库，支持减少动态效果的系统设置。
- 移除示例趋势图，将只有摘要的文章区调整为可展开的咨询指南，增加常见问题。
- 页脚只保留已有内容，页面空链接归零；补上主要内容区域与键盘跳转入口。
- 公司数字与团队介绍经用户在本次对话确认真实并可公开后保留。
- 修正重复头像：王晓婷使用姓名头像，等待本人独立照片。
