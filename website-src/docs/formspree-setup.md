## 账号与收件邮箱

1. 打开 <https://formspree.io/register>，自行设置账号密码、阅读并确认条款；已有账号可直接登录。
2. 完成 Formspree 发送的账号验证邮件。
3. 在 Dashboard 创建表单，名称可用“长伴咨询网站咨询”，通知收件邮箱设置为 `wangjiano@cbrlzy.com`。如果要求验证该邮箱，先在邮箱内完成验证。
4. 在表单 Integration 页面复制 Form Endpoint，格式为 `https://formspree.io/f/表单ID`。只需提供这个公开地址，不需要密码、管理 API Key 或 GitHub Token。
5. 检查表单已激活、通知接收人正确、当前套餐额度可用。使用现有免费范围，任何付费升级均需用户另行决定。

官方流程：[创建 HTML 表单](https://help.formspree.io/articles/building-your-form/building-an-html-form)。Formspree 会接收并保存咨询内容，也会发送通知邮件；网站已有对应说明。

## 配置与验证

上线前需要一封标明“网站功能测试”的真实咨询，核对 Formspree 的 Submissions 记录与收件邮箱（包括垃圾邮件夹），确认字段、中文与多行内容正确。真实邮件尚未发送；账号配置完成后先确认测试内容与收件人，再发送验证。

保持服务的反垃圾和人机验证保护。如果实际配置返回 CAPTCHA 错误，当前页面会明确失败并提供邮件草稿；应按该表单实际要求接入验证组件后再上线，不能将验证失败当作成功，也不要自动关闭安全保护。

## 提交行为

- 未配置时仅生成本地邮件草稿，不调用外部服务。
- 在线模式提交中禁止重复点击与修改字段。
- 仅在 HTTP 成功且返回明确的 JSON 接收确认时显示“咨询已提交”；不声称收件箱已经收到邮件。
- 校验失败、网络失败、超时、服务错误、额度限制均保留填写内容。超时或结果不明不自动重试，以免重复发送。
- 邮箱、电话、微信均可作为联系方式；仅合法邮箱值用于 Reply-To。
- 提交字段固定，不上传额外私人数据；隐藏 `_gotcha` 防垃圾字段符合官方规则。
- 可改用邮件草稿，手动发送至现有咨询邮箱。
