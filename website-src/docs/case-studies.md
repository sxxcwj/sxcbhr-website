# 咨询案例内容维护

案例内容集中在 `src/data/consultingCases.ts`，首页展示组件为 `src/components/CaseStudies.tsx`。首页、桌面及手机导航和页脚显示对应入口；没有内容时不展示空栏目。

0.4.0 包含三个 `kind: 'example'` 的模拟咨询情境，经用户于 2026-10-08 授权发布。页面明确标为“示例情境 · 非历史客户案例”，使用“建议工作路径”和“可形成的交付”，不描述已实现的改善效果。

正式客户案例使用 `kind: 'client'`，必须先取得用户提供的真实项目事实及公开确认，再替换客户背景、实际开展工作和项目成果，不能只改类型而保留示例内容。

## 每个案例所需事实

- 客户名称，或可公开的匿名描述。
- 客户背景：行业、业务或管理阶段。人数等信息仅在有真实资料且允许公开时使用。
- 项目服务类型与一个清晰标题。
- 客户当时面临的问题。
- 长伴咨询实际开展的工作。
- 实际成果：可使用制度、方案、工具、培训等交付结果；改善比例、周期等数字必须有依据并获得公开授权。

文字可以整理为专业、易读的表述，但不得把建议包装成已完成工作，或把交付结果包装成未经验证的经营效果。用户未提供的数据不补造，未确认的案例不加入公开列表。匿名案例不得保留能反推出客户或个人身份的细节。

修改后进行类型检查、构建及浏览器验证，核对内容、导航、手机布局和咨询入口。正式发布时同步构建文件到仓库根目录，保留既有历史和文件。
